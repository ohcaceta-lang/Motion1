## Linguagem visual
- **Paleta:** vermelho intenso (#D10A0A) → vinho escuro (#5A0000) em **gradiente animado tipo "mesh"**, alternando com branco puro. Preto só nas silhuetas. Os logos de clientes trazem cores próprias só no trecho de cases.
- **Tipografia:** sans geométrica arredondada (tipo Poppins/Gilroy) bold para palavras-chave, regular/itálico para conectores. Destaque por **caixa sólida** (branca ou vermelha) atrás da palavra.
- **Interface como linguagem:** cursor de mouse clicando, pílulas/tags tipo botão, ícones em botões circulares com relevo (neumorfismo), cards arredondados.
- **Ícones-metáfora:** lixeira (descartar o que não funciona), olho (atenção/reconhecimento), globo no "O" de WORLDWIDE.

## Ritmo
- Rápido no início (troca a cada ~1 s até 3 s), depois blocos de **4–6 s** por ideia.
- Mistura de **cortes secos em contraste** (vermelho ↔ branco) com animações dentro da mesma cena (pílulas caindo, ícones aparecendo).
- Estrutura clássica de agência: **problema → solução (clareza) → pilares → frase de efeito → cases/logos → números → benefícios → prova social → CTA → logo.**

## O que reaproveitar nos nossos vídeos
1. **Fundo em gradiente animado (mesh)** de uma cor só: dá movimento constante mesmo quando o texto está parado.
2. **Cursor clicando para destacar a palavra** (a palavra ganha caixa colorida): simples e muito eficaz.
3. **Problemas como pílulas caindo na lixeira**: visualiza "descartar o que não funciona".
4. **Bloco de números** com onda branca + ícone circular + número grande: ótimo para mostrar resultados.
5. **Alternância vermelho ↔ branco** a cada bloco para reacender a atenção.
6. **CTA com palavra gigante recortada** ("MOVE") antes do logo.
