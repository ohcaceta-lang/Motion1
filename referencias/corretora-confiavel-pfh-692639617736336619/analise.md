## Linguagem visual
- **Branco + P&B + um acento amarelo** (#F2E14C): o amarelo aparece em holofotes, tarjas nos olhos e auréola, sempre apontando "o que importa". Verde só no círculo de "Fast".
- **Tipografia:** serifada condensada em **itálico** (tipo "Instrument Serif"/"PP Editorial") para frases + sans bold condensada para as palavras-chave ("Regulated", "Fast"). Mesma fórmula "palavra pequena itálica + palavra grande bold".
- **Fotos P&B com tarja nos olhos**: visual de "denúncia/revelação", bem forte para gancho.
- **Objetos 3D metálicos** (cadeado, escudo) para os pilares, como ícones-herói.
- **Padrão isométrico branco** como fundo de transição: textura sem competir com o texto.

## Ritmo
- Uma ideia a cada **2–3 s**, com narração guiando.
- Transições: **whip com motion blur**, **zoom blur radial** e foco/desfoque (rack focus) nas fotos.
- Estrutura: **"a verdade que ninguém fala" → 3 negações ("not another…") → lista de dores → "soa familiar?" → virada → 4 pilares "Highly X" → slogan + logo.**

## O que reaproveitar nos nossos vídeos
1. **Gancho "a verdade sobre…" com tarja nos olhos**: cria curiosidade e tom de revelação.
2. **Repetição "Not another…"** (anáfora) para rejeitar o comum antes de apresentar a solução.
3. **"Soa familiar?"** depois de listar as dores do público: gera identificação.
4. **Pilares em série com a mesma estrutura** ("Highly ___") + um objeto 3D para cada um.
5. **Um único acento de cor (amarelo)** numa peça P&B: direciona o olhar.
6. **Slogan "You asked. We delivered."** no fechamento: curto e com ritmo.
